# Multi-Channel Support Hub

## Setup

1. Create the Supabase tables by running `schema.sql` in the Supabase SQL Editor.
2. Backend: copy `backend/.env.example` to `backend/.env`, add your Supabase credentials, then run `npm install` and `npm start`.
3. Frontend: optionally copy `frontend/.env.example` to `frontend/.env`, then run `npm install` and `npm run dev`.

The channel services operate in demo mode until their environment credentials are configured.
